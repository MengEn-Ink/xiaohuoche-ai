# 小火车日报视觉规范

本规范以仓库 `style/references/605/` 的 605 真稿为唯一 ground truth；#528、#604 仅作补充参考。0908、0910 是后续拼贴实验版，不得用来覆盖真稿事实。目标不是做整齐的企业海报，而是保留骑行群内部刊物的“生猛、草根、手工拼贴”气质。

## 风格骨架

- 一种天蓝底贯穿整页：内容连续生长，不按屏轮换底色，不用厚黑线硬切章节。
- 纵向连续拼贴：`大字短梗 → 全屏截图/人物抠图 → 一句证据`，一个素材只占一个主题。
- 非对称但可读：标题、图片、贴纸允许 `-2deg` 到 `2deg` 的轻微错位；正文卡片保持接近水平，不能以凌乱牺牲阅读。
- 图文混排：原生微信/Strava 截图可全屏打底，粗白边人物抠图压在最前，书法大字可穿插在人物层后；不做白色信息卡或官网卡片阵列。
- 梗先于说明：大标题直接截取原话中的笑点，正文只补齐事实。禁止为追求“历史味”虚构人物、结果或评价。

## 色彩

使用高饱和、硬边界配色：

| 用途 | 推荐颜色 |
|---|---|
| 黑色描边/正文 | `#050505` |
| 天蓝底纸 | `#A6DBF5` |
| 深蓝强调 | `#0047FF` |
| 红色强调 | `#FF2B00` |
| 黄色标题 | `#FFF200` |
| 绿色点缀 | `#39FF14` |
| 白色轮廓/撕纸 | `#FFFFFF` |

全篇保持天蓝底纸。荧光绿、亮黄、白、粉紫、青、蓝紫只用于逐行大字和局部贴纸，不轮换整屏背景。

## 字体与标题

- 页面最大宽度：1080px；导出 PNG 时固定 1080 CSS px。
- 俱乐部可见缩写固定为 `XZQ`。
- 主标题使用特粗黑体或手写综艺体，搭配 4–7px 黑描边、8–14px 硬阴影。
- 章节标题可占屏宽 70%–95%，桌面端行高至少 `1.08`，移动端至少 `1.14`。
- 强调词用矩形色块另起一行，与上一行至少间隔 `12px`；不要让描边、阴影互相压字。
- 标签使用矩形色块和 3px 以上黑边，不使用轻柔胶囊作为主视觉。

## 版式参数

- 章节上下内边距：`72–108px`；通过截图、人物与大字的连续叠压形成长图节奏，不使用黑线切屏。
- 不使用栏目标签或白色信息卡阵列；证据优先保留原生截图 UI。
- 正文展示字以 68px 为绝对下限；长文案横向成行并按完整语义自然换行，禁止竖排、窄列和逐字列展示。只有总字数不超过 10 字、最多 2 个短句且单句不超过 6 字的口号可以列式展示。
- 轻倾斜：图片可用 `rotate(-1.4deg)` / `rotate(1.2deg)` 交替；正文色块控制在 `±0.7deg`。
- 三层叠压顺序固定为：原生截图底层 → 大字中层 → 粗白边加外层黑边的人物抠图前层。安全区仍须真实标注。
- 屏间使用白色撕纸边或图片自然过渡，不使用粗黑分隔线。
- 禁止 `WEEKLY RIDE`、`ISSUE`、`WHOOSH` 等英文装饰，以及“01 · 栏目”类标签。
- 移动端改为单列，间距不少于 `28px`；倾斜角减半，防止阴影被裁切。

## 图片与贴纸

- 每张图片只使用一次；同一事件可使用两张不同照片，不得复制同一文件填版。
- 默认允许按当期内容自由选择、搜索贴图或表情包；优先使用 `style/stickers/` 已审核素材，外部素材必须下载到当期 `assets/`，不得热链。
- 每屏贴图或表情包控制在 1–2 个，只负责强化情绪和笑点，不得借贴图新增事实、人物或结论。
- 贴图适合进入标题边缘、图片边框或明确空区；不允许压住标题字面、正文、人脸、服装标识、截图信息和微信水印安全区。
- 封面合影可横向裁切；截图、路线图和设计稿优先 `object-fit: contain`。
- 给照片使用直角或小圆角黑框、硬阴影和少量旋转，模拟历史长图的手工拼贴。
- 人物剪贴只允许非生成式前景分割、裁切与等比例放大：透明人物图的 RGB 像素必须来自原图；禁止换脸、美颜、磨皮、补身体、重绘五官或改服装姿势。
- 背景纯色和大字由 HTML/CSS 放在透明人物图后方，不写进图片；抠图质量不足时改用原图裁切，绝不使用生成式修图。
- 大头贴比例优先：群像头部与上半身占画面约 80%–90%，单人头像可接近满版；允许次要手臂、车轮在边缘裁切，不得裁脸、Logo 或服装文字。
- 标题和正文均按“能大不小”处理：章节标题桌面端可到 `98px`，正文展示字不得低于 `68px`；移动端审阅页可以响应式缩放，但最终 1080px 导出图必须回到 68px 以上。
- 群像保留全部人物与站位；单人保留脸部、姿势和服装标识。大字只用已确认口号，不遮挡脸、身体或服装关键信息。
- 同一日报只使用原图或合成图其中一个版本，避免内容重复。
- 可用 CSS 伪元素做“胶带”和编号贴纸；胶带不遮挡图片主体，贴纸文字只使用原素材中的词。
- 图片说明只写可确认内容，不推断人物、地点或活动结果。

## 动效与截图

网页浏览时只保留轻量渐入、返回顶部和点击看大图。导出前必须：

1. 等待字体与全部图片加载完成。
2. 注入截图样式，关闭动画并强制内容可见。
3. 隐藏进度条、返回顶部和灯箱等固定交互控件。
4. 同时输出整页 PNG 和带少量重叠的分屏 PNG，避免超长图被公众号过度压缩。

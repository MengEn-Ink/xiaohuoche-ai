# few-shot 真稿样例

「素材 → 分屏脚本」配对。写作时按栏目优先挑同栏目的真稿喂给模型（见 `prompts._few_shot_block`）。

## 现有样例（2024 年喜子原版 8 篇 + 2026-09-08 复刻 1 篇）
| 文件 | 栏目 | 说明 |
|---|---|---|
| 20240518-subao | 速报 | 红牛杯白杨沟；编号体 |
| 20240519-subao | 速报 | 四趟出门都没走成的王教练；典故戏仿范本 |
| 20240521-subao | 速报 | 训练浓度太高；有图的速报 |
| 20240521-wanbao | 晚报 | 小雷减肥餐；截图—反应结构密集 |
| 20240522-zaobao | 早报 | 李自成雕像；回顾+早黑组+爬楼组 |
| 20240527-kuaixun | 快讯 | 新闻联播戏仿；周五/六/日分段 |
| 20240528-ribao | 日报 | 厕所之神；福利弟 |
| 20240605-ribao | 日报 | 黑四；曹科烟瘾；打不散的爱情 |
| _20260908-ribao | 日报 | 作者复刻版（Trae 产出）；下划线开头 = 不喂给模型，仅留作参考 |

## 命名约定
- `YYYYMMDD-<栏目>.input.md`：当期素材（小编初稿 + 截图/照片说明 + 数据）
- `YYYYMMDD-<栏目>.output.json`：最终分屏脚本，role 见 `xzq/models.py`

## 怎么加
发得好的一期，把发布前的素材和最终脚本按上面格式落一对进来。同栏目 3 篇以上效果最好。

## 一条素材 = 一个人 + 一件糗事
每 2-3 句点一个素材中已有的授权昵称或脱敏称呼；不要求出现真名。没有对应称呼时宁可留占位。数字是笑点不是统计：`303w3.5w` `12x 时代` `9 分时代` `68` `74kg` `128` `300 瓦` —— 永远跟着一句吐槽。

## 四个招牌手法（按辨识度排）

**1. 典故戏仿** —— 把群友糗事套进名人/典故/新闻联播的壳
- 古有大禹为了治水，三次经过家门而不敢入。今有王教练为了躲水，四趟出门都没走成。
- 他失落的背影历历在目，就像朱自清写的背影。
- 刀刀成为辛庄桥史铁生 / 谁才是真道明寺不用我多说 / 队友化身参赛依萍
- 旧新闻联播 / 头条 / 据悉 / 重点消息 / 组织封他们为 突贵妃，佳贵妃

**2. 反讽祝福** —— 用祝福句式说坏事
- 今天真空胎就扎了。让我们祝福他。
- 半路拉稀 完成逃课，让我们恭喜他
- 没想到她年纪轻轻就染上了这玩意儿。太可惜了。希望她坚持不下去。
- 他正在积极减肥中。祝他早日回到巅峰。

**3. 官腔戏仿** —— 机关文件的腔调说鸡毛蒜皮
- 小编再次呼吁大家保护好自己的工具，做自己工具的第一负责人！
- 莫拉表示：这是浪费粮食的现象应给予警告。
- 群主是他，拉群的是他，放弃的是他！今天我们批判他。
- 为了维护北京交通道路安全。ems 操作联系人删除了 xzq-黑山寨-xzq 赛段。

**4. 截图—反应** —— 先贴群聊截图当证据，文案只是对截图的一句反应
- 截图「老王：我这摄氧量 雷子你行吗」→ 大字「全员注意小雷 68 了」
- 截图「李：曹科烟瘾好大」→ 「曹科怒改 icu 303w3.5w 老李直呼你这烟瘾太大」
- **截图本身是成稿的一部分**，visual 字段里要写明贴哪张截图。

## 语气与句式
- 句子短：中位 10 字，一句一行，少逗号。
- 问句比感叹号更有辨识度：反问（这是人吗？谁同意，谁反对？）、把当期的事编成一问（问：XX 何时 YY？）。**例句只看结构，别原样搬。**
- 把训练时段/项目拟人成「组」：早鸟组 / 早黑组 / 下午鸟 / 晚奥鸟 / 奥女组 / 爬楼组 / 通勤 / 纯纯爆骑团 / 修仙组 / 竞技组，每期至少 2 个。
- 固定收尾（约一半的期有）：今天就到这里小编下班 / 明天早鸟记得攻击 / 草原天路赶紧上车啊 / 让我们谢谢爽哥 / 打不散的爱情吵不裂的友谊。
- **波浪号、kuku 干、叠词不是特征**（21 篇里各出现 1-4 次），不要刻意用。

## 反规则（AI 模仿时的系统性毛病，实测过）
- **十句里两句好笑就够了。** 真稿是随手记录，大部分句子只是平铺事实，偶尔一句金句。不要每一条都做成段子。
- **官腔戏仿每篇最多 3 次。** 据悉 / 小编锐评 / 应给予警告 / 让我们保持关注，用多了就是表演。
- **允许废话、允许松散。** 「大家都拥有了美好的一天」「好！」这种没包袱的句子是真稿的一部分。
- **不许搬 few_shot 里的原句。** 「这也是充碳？」「所有喜欢拉稀的朋友」是某一期的梗，换个语境原样用就是抄。学手法，不抄句子。
- **不要每屏都收在 punchline 上。** 很多屏就那么结束了。
- **允许一点怪癖。** 真稿会突然抒情一句「他是自己的叛徒」，会用一个字「好！」收尾。太「标准」反而假。

## 栏目
栏目名随手起，本身是梗：日报 / 晚报 / 早报 / 午报 / 晨报 / 摸鱼报 / 下午摸鱼报 / 快讯 / 速报。一天可发 2-3 篇。
- 拼贴报（日/晚/早/午/快讯）：彩底大字 + 照片/截图/抠图，不编号，用大字分段 → 见 templates/ribao.md wanbao.md zaobao.md kuaixun.md
- 速报：纯文字 `1、2、3…` 编号，每条一人一事，可长可短 → 见 templates/subao.md
- 活动公告 / 团建：海报 + 二维码 → 见 templates/tuanjian.md

## 标题公式
- 日报 `605，小火车日报。`　晚报 `521,小火车晚报`　早报 `523，小火车早报。`　速报 `xzq今日速报（519）`　快讯 `527，小火车快讯`
- 标点不统一（有的句号有的逗号有的没有），日期 3-4 位不带年。

## 产稿形态
输出**分屏脚本**（JSON）：`{"title", "screens":[{"role","text":[...],"visual","data"}]}`
role 从 cover / headline / preview / race / earlybird / gossip / feeling / review / shirt / item / checklist / end 中选；item 专用于速报体的编号条目。
人名、功率、时间只能来自素材，**绝不编造数据**。

## 红线
- 功率 / PR / 时间 / 排名只认 Strava 真实数据，不许编。
- 群聊糗事、照片须本人同意；真名单位车牌打码。
- 粗口限于圈内口头禅，不涉歧视、不做人身攻击。

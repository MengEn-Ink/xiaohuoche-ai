# 模板 · 速报（subao）

纯文字，`1、2、3…` 编号，每条一人一事。可长可短：一条可以是一句话（"4、xzq 今天中午吃大盘鸡。"），也可以是一段叙事（王教练四趟出门都没走成）。role 全用 `item`；开头可加一条 `headline`。

- 第一条通常是当天最大的事，配典故戏仿开场（古有…今有…）。
- 中间条目短，事实 + 一句反应。
- 结尾一个字或一句：`好！` / `ps.大爷第十，祝 xzq 越来越红火`。
- 无图或只配一张合影 / 一张 Strava 排行榜。

范例见 few_shot/20240518-subao、20240519-subao、20240521-subao。

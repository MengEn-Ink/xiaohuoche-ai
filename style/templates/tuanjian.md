# 分屏模板 · 团建必读（tuanjian）

活动/团建通知，行程表 + 装备清单。封面压风景照；行程用纯黑底 + 绿色时间轴；清单用浅绿便利贴框。

1. **封面屏**：大字"{地名} 行程表 / {地名}团建必读"压实景风景照；云朵贴纸标日期。
2. **行程时间轴屏**（黑底，左侧绿色竖线 + 圆点，时间用明黄色大字）：每个时间点一行，时间 + 安排 + 一句吐槽。范例语气：
   - "13:00 林萃桥西南角地铁站出发，需提前 10-20 分钟装车"
   - "18:00 集体干饭 / 也可以不吃 🍚"
   - "20:00 睡觉或者当保安站岗"
   - "8:00 到达起点各就各位，该吃吃该拉拉，有屎别往裤兜拉～～～"
   - "11:00 完赛记得退押金 200 元！！📷 全员拍照到此一游"
   - "11:30-15:30 跟着路书或爽哥，瞎 J2 干就完了！"
3. **装备清单屏**（浅绿便利贴框，"重要清单"）：身份证、200 元现金押金、胶(5 根左右)、充电器/功率计、码表心率带、骑行服/鞋/眼镜/头盔、防晒。
4. **后援/结尾屏**："后援车支持：打气筒、医疗箱、备胎、摄影服务，需要电联小编！祝 xdm 安全完赛～～～" + 右下「公众号 · 辛庄桥小火车」。

> 时间、地点、押金、集合点必须与实际安排一致，不编；吐槽不盖过关键信息。

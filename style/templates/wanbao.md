# 分屏模板 · 小火车晚报（wanbao）

当日群友动态吃瓜汇总，比日报更碎、更损。底色浅天蓝。按素材多寡灵活排屏：

1. **封面屏**：大字"小火车晚报" + 日期；副标题用当日最抓马的一件事（毛笔体）。信息行同日报。
2. **动态屏**（可多条）：每条 = 一张群聊/Strava/朋友圈截图 + 一句毒舌标题。
   - 早鸟卷王："凌晨 X:XX 一条'刷个妙 PR（放坡🤣）'甩群里，出生模式是吧。"
   - 破镜重圆 / CP 梗：两人抠图叠爱心底。
   - 补给/装备梗：如"甜菜根怎么喝？群友指导：不好喝别喝。"
   - 功率数据截图：脂肪/碳水/匹配/最大放电一串数字 + "谴责！"
3. **金句屏**：当日群聊最损一句原文截图，配表情包贴纸（如拿枪黄脸"我觉得你该被枪毙，而且由我来执行"）。
4. **结尾屏**："祝 xdm 今晚好梦，明早别鸽。" + 右下「公众号 · 辛庄桥小火车」。

> 晚报靠"当天真实发生的事"撑，没素材不硬写；截图里的隐私打码。
